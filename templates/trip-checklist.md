# 出发清单

[返回首页](../README.md) · [第一次滑雪](../docs/01-first-day.md)

## 订行程前

- [ ] 选定单板或双板、日期、人数和出发地。
- [ ] 雪场初学区开放，课程已确认项目、人数与时长。
- [ ] 买的是正确的滑雪票，已核对雪具、护具、柜子和计时规则。
- [ ] 交通、住宿、课程和租赁没有重复计费。
- [ ] 退改、天气停运和接驳末班时间已确认。
- [ ] 保险适用于本次活动与日期，已阅读主要保障和除外条款。

## 行李

- [ ] 证件、预约凭证、手机、充电设备。
- [ ] 排汗层、中间层、防风防水外层。
- [ ] 一双合适的滑雪袜、防水保暖手套、护脸/脖套。
- [ ] 头盔、雪镜与护具，或已确认可租和尺寸。
- [ ] 防晒用品、饮水、少量食物、替换干衣物。
- [ ] 回程普通鞋，湿衣物临时分装袋。

## 到场

- [ ] 试鞋后站立和屈膝，无麻木与明显压痛。
- [ ] 头盔、雪镜一起检查，扣具稳定，视野清楚。
- [ ] 固定器由工作人员确认适配和设置。
- [ ] 保存雪道图、救援电话、柜号和归还地点。
- [ ] 找到教练，说明水平、目标和身体活动限制。

## 每次出发滑行前

- [ ] 看上方来人、下方空间、交叉口和停止位置。
- [ ] 雪道开放，任务与能力、雪况、人流匹配。
- [ ] 视线清楚，器材正常，体力足够。

## 结束

- [ ] 完整归还租赁用品，核对押金和实际费用。
- [ ] 换干衣物、干燥装备，按时到返程集合点。
- [ ] 记录今天能稳定完成什么，下次先复习什么。
