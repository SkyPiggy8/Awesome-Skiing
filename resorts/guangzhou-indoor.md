# 广州热雪奇迹：第一次去，从广州北站怎么走

[雪场目录](README.md) · [交通速查](transport.md) · [知识地图](../docs/00-knowledge-map.md)

**室内真雪｜广州花都｜核验：2026-10-25。** 地址为花都区凤凰北路 63 号广州融创茂 F1。适合广州及周边希望分次体验或练习的人；跨城来是否划算，需把往返交通加进预算。场馆名称也常以“广州融创雪世界”出现在旧攻略中。

## 广州北站到雪场，预留多久

| 方式 | 怎么走 | 时间口径 |
| --- | --- | --- |
| 城际 + 步行 | 国铁广州北站出站 → 按指引到城际 **花都站** → 乘停靠 **花城街站** 的列车，一站 → D 口 → 步行至融创茂与雪场入口 | 整段可先按 **45–75 分钟**安排；这是含换乘、普通候车和步行的编辑规划余量，不是实测或班次承诺，等车较久需增加 |
| 出租车/网约车 | 按所到站房的上车点上车，目的地填雪场所在融创茂入口 | 票务页面标示车程约 **20 分钟**；实际可先按车上 **20–35 分钟**、含找车和进馆 **30–50 分钟**留量，堵车另加 |

**不要把广州北站、城际花都站、地铁花都广场站当成同一站。** 国铁与城际的站名不同，换乘要走通道。城际线路和列车终到站可能调整，依据站台显示核实“停靠花城街”，不用只凭旧攻略里的方向名称上车。

上述路线来自 [广州热雪奇迹 2026 年 9—12 月官方公告](https://www.sina.cn/news/detail/5343007041652099.html) 与 [Klook 场馆交通说明](https://www.klook.com/zh-CN/activity/23416-sunac-snow-park-admission-ticket-guang-zhou/)；国铁出站广场可参看 [花都区交通运输局指引](https://www.huadu.gov.cn/zfxxgkml/gzshdqjtysj/content/mpost_9476142.html)。Klook 是售票平台，其旧公交列表不作为本页现行公交依据。

到融创茂后还要找入口、换票、存物、领装备、试鞋。第一次在上述交通之外再留 **45–60 分钟准备余量**，周末按实际排队增加；它不代表雪票一定从进雪区才起算。约课前确认集合时间与计时规则。

## 第一次怎么买票

官方当期说明将滑雪和娱雪分开，滑雪又有时长与区域区别。只想拍照玩雪先看娱雪；想学板上移动则找对应滑雪区域及入门课。购买全区票也不代表能力适合所有雪道。

该公告的滑雪基础配置列有衣服、板鞋、头盔和柜子；购买时逐项核对你的具体商品。**雪镜、手套、护具是否另租另买不要自行推断。** 贴身排汗层、袜子、合适护脸和防水手套提前准备，详见 [装备清单](../docs/03-equipment.md)。

## 不想先花很多教练费

同一份 **2026 年 9—12 月公告**列有平地公开教学：每日 11:00、12:00、15:00、16:00，每场约 30 分钟，法定节假日及圣诞节除外。到访前问清预约方式、人数、单双板安排与当天是否照常开课。公开课是体验资源，进阶滑行仍按实际能力与指导安排。

## 一场的预算怎么列

以下是**编辑占位预算，不是查到的当天售价**，约 3–4 小时场次、人均，不含跨城高铁和住宿。

| 项目 | 规划预留（元/人） |
| --- | ---: |
| 滑雪场次票 | 250–550 |
| 票外必要租赁/小件 | 0–150 |
| 餐饮 | 50–100 |
| 广州当地往返交通 | 30–150 |
| 基础合计 | **330–950** |
| 如另选付费入门课，预留 | 300–800 |
| 含一次付费课合计 | **630–1,750** |

票含的项目不重复计费；自己已经有的贴身用品不重复当每次租赁。公开课如确认免费，课程项记 0，但不能把它与完整私教课视为同一服务。保险、额外购物和预备金按个人安排另加。
