# 北京南山：怎么去、怎么学、怎么做预算

[雪场目录](README.md) · [预算口径](../docs/06-budget.md) · [返回首页](../README.md)

**区域：北京密云｜资料整理：2026-10-24**

## 先认识这个目的地

南山位于北京密云，提供单双板租赁及不同级别雪道；官方介绍列出密云站与市区直通车等到达方式。 来源见页末。以下适用人群、行程和预算是编辑建议，不是亲测评价或官方承诺。

**适合怎样的计划：** 北京及周边第一次体验、能反复安排单日课程的人。优先比较可用教学区、换装与排队成本，不因公园或高级道宣传改变练习计划。

## 到达与住宿

以北京为出发点，比较自驾、官方直通车或高铁到密云站后接驳。官方站点和车次会变化，预约时问清回程集合点。外地读者另计到北京的费用。

单日往返通常更简单；跨城或连续两天上课再考虑密云住宿。住宿便宜与否要连同第二天到雪场的交通比较。

## 新手安排

到场后完成试鞋和初级区课程，午后只复习已学动作。先核实票种是否包含板鞋，服装、护具和储物另查；夜场不能直接延长日场票权益。

## 人均预算演算

**以下是用于规划的假设区间，不是本雪场报价，也未完成当季询价。** 成人、非节假日的常规出行场景；不采用促销价和住滑打包价。住宿按双人房两人分摊。若实际报价超出区间，以实际报价重新计算。

| 输入项目 | 规划预留（元/人） |
| --- | ---: |
| 雪票 / 滑雪日 | 150–350 |
| 基础租赁与必要小件 / 滑雪日 | 80–180 |
| 餐饮 / 滑雪日 | 60–150 |
| 当地短途交通 / 滑雪日 | 40–150 |
| **单日基础小计** | **330–830** |
| 住宿 / 人 / 晚 | 150–450 |
| 约两小时入门小班课 / 人 / 次 | 300–800 |

- **一天滑雪 + 一次课，不住宿：630–1,630 元/人。**
- **两天滑雪 + 一晚住宿 + 一次课：1,110–2,910 元/人。** 计算为 2 × 基础小计 + 住宿 + 课程。
- **另加**出发城市往返大交通、机场至山区等长距离接送、独立景区门票、保险及杂费、单房差、额外课程与预备金。西岭等景区目的地尤其要另核上山门票与索道，吉克普林等要另核景区交通。
- 若雪票含板鞋，或酒店含雪票，先用真实套餐替换对应行，再求和。这个保守的单买模型不能直接拿来判断套餐贵不贵。

## 出发前确认

- [ ] 初级区是否开放，单双板课程是否分组。
- [ ] 当前票是否含基础雪具，服装与柜子另收多少。
- [ ] 直通车预约、往返站点与末班时间。
- [ ] 用出行日期的官方报价替换上表；核对退改、时长、租赁、储物和押金。
- [ ] 保存当日雪道图与救援电话；核实所选教学区域的开放状态。
