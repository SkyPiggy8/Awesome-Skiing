# 北京南山：怎么去、怎么学、怎么做预算

[雪场目录](README.md) · [预算怎么算](../docs/06-budget.md) · [返回首页](../README.md)

**区域：北京密云｜资料整理：2026-10-24**

## 先看它适不适合你

南山位于北京密云，提供单双板租赁及不同级别雪道；官方介绍列出密云站与市区直通车等到达方式。

**更适合：** 北京及周边第一次体验、能反复安排单日课程的人。优先比较可用教学区、换装与排队成本，不因公园或高级道宣传改变练习计划。

## 到达与住宿

以北京为出发点，比较自驾、官方直通车或高铁到密云站后接驳。官方站点和车次会变化，预约时问清回程集合点。外地读者另计到北京的费用。

单日往返通常更简单；跨城或连续两天上课再考虑密云住宿。住宿便宜与否要连同第二天到雪场的交通比较。

## 新手安排

到场后完成试鞋和初级区课程，午后只复习已学动作。先核实票种是否包含板鞋，服装、护具和储物另查；夜场不能直接延长日场票权益。

## 大概要花多少

这张表按成人、非节假日、双人拼房来估，促销和住滑价没算。它的用途是帮你出发前留预算，订票时换成自己的实际价格。

| 输入项目 | 规划预留（元/人） |
| --- | ---: |
| 雪票 / 滑雪日 | 150–350 |
| 基础租赁与必要小件 / 滑雪日 | 80–180 |
| 餐饮 / 滑雪日 | 60–150 |
| 当地短途交通 / 滑雪日 | 40–150 |
| **单日基础小计** | **330–830** |
| 住宿 / 人 / 晚 | 150–450 |
| 约两小时入门小班课 / 人 / 次 | 300–800 |

- **一天滑雪 + 一次课，不住宿：630–1,630 元/人。**
- **两天滑雪 + 一晚住宿 + 一次课：1,110–2,910 元/人。** 计算为 2 × 基础小计 + 住宿 + 课程。
- 大交通、保险、单房差、额外课程和预备金另算。偏远山区的机场接送、景区门票和索道也要单独查。
- 票里含板鞋、酒店含雪票时，删掉重复项目再加总。比较住滑套餐也按这个办法。

## 出发前确认

- [ ] 初级区是否开放，单双板课程是否分组。
- [ ] 当前票是否含基础雪具，服装与柜子另收多少。
- [ ] 直通车预约、往返站点与末班时间。
- [ ] 用出行日期的官方报价替换上表；核对退改、时长、租赁、储物和押金。
- [ ] 保存当日雪道图与救援电话；核实所选教学区域的开放状态。
