# 长白山万达：怎么去、怎么学、怎么做预算

[雪场目录](README.md) · [预算怎么算](../docs/06-budget.md) · [返回首页](../README.md)

**区域：吉林白山抚松区域｜资料整理：2026-10-24**

## 先看它适不适合你

万达官网介绍了长白山度假区的滑雪场、分级雪道、酒店和其他度假设施。这里的滑雪与长白山天池景区游览是不同项目。

**更适合：** 想把滑雪课、酒店和家庭度假安排在同一目的地的人。挑选住滑套餐时，应从每位游客的权益出发，而不是只看房间总价。

## 到达与住宿

核对所选机场、车站到度假区的实际路线，优先确认订单是否含接送。天池景区方向与酒店位置不必然一致，安排观光时单独留一天或半天。

多个酒店与楼栋的雪票、租赁和接驳权益可能不同，退房日能否用雪票尤其容易遗漏。能滑进滑出也要确认连接路线适合自己的水平。

## 新手安排

第一天在教学区练习，家庭成员按滑雪与娱雪分组。不要把温泉、漂流、景区等全部塞到高强度滑雪后，按体力留出休息。

## 大概要花多少

这张表按成人、非节假日、双人拼房来估，促销和住滑价没算。它的用途是帮你出发前留预算，订票时换成自己的实际价格。

| 输入项目 | 规划预留（元/人） |
| --- | ---: |
| 雪票 / 滑雪日 | 280–600 |
| 基础租赁与必要小件 / 滑雪日 | 100–220 |
| 餐饮 / 滑雪日 | 100–220 |
| 当地短途交通 / 滑雪日 | 50–180 |
| **单日基础小计** | **530–1,220** |
| 住宿 / 人 / 晚 | 250–650 |
| 约两小时入门小班课 / 人 / 次 | 350–1,000 |

- **一天滑雪 + 一次课，不住宿：880–2,220 元/人。**
- **两天滑雪 + 一晚住宿 + 一次课：1,660–4,090 元/人。** 计算为 2 × 基础小计 + 住宿 + 课程。
- 大交通、保险、单房差、额外课程和预备金另算。偏远山区的机场接送、景区门票和索道也要单独查。
- 票里含板鞋、酒店含雪票时，删掉重复项目再加总。比较住滑套餐也按这个办法。

## 出发前确认

- [ ] 入住日、退房日和儿童的雪票权益。
- [ ] 酒店套餐是否含板鞋，护具与课程是否另付。
- [ ] 所到机场和车站是否在免费接驳范围内。
- [ ] 用出行日期的官方报价替换上表；核对退改、时长、租赁、储物和押金。
- [ ] 保存当日雪道图与救援电话；核实所选教学区域的开放状态。
