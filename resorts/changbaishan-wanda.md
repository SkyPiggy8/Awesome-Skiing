# 长白山万达：怎么去、怎么学、怎么做预算

[雪场目录](README.md) · [预算口径](../docs/06-budget.md) · [返回首页](../README.md)

**区域：吉林白山抚松区域｜资料整理：2026-10-24**

## 先认识这个目的地

万达官网介绍了长白山度假区的滑雪场、分级雪道、酒店和其他度假设施。这里的滑雪与长白山天池景区游览是不同项目。 来源见页末。以下适用人群、行程和预算是编辑建议，不是亲测评价或官方承诺。

**适合怎样的计划：** 想把滑雪课、酒店和家庭度假安排在同一目的地的人。挑选住滑套餐时，应从每位游客的权益出发，而不是只看房间总价。

## 到达与住宿

核对所选机场、车站到度假区的实际路线，优先确认订单是否含接送。天池景区方向与酒店位置不必然一致，安排观光时单独留一天或半天。

多个酒店与楼栋的雪票、租赁和接驳权益可能不同，退房日能否用雪票尤其容易遗漏。能滑进滑出也要确认连接路线适合自己的水平。

## 新手安排

第一天在教学区练习，家庭成员按滑雪与娱雪分组。不要把温泉、漂流、景区等全部塞到高强度滑雪后，按体力留出休息。

## 人均预算演算

**以下是用于规划的假设区间，不是本雪场报价，也未完成当季询价。** 成人、非节假日的常规出行场景；不采用促销价和住滑打包价。住宿按双人房两人分摊。若实际报价超出区间，以实际报价重新计算。

| 输入项目 | 规划预留（元/人） |
| --- | ---: |
| 雪票 / 滑雪日 | 280–600 |
| 基础租赁与必要小件 / 滑雪日 | 100–220 |
| 餐饮 / 滑雪日 | 100–220 |
| 当地短途交通 / 滑雪日 | 50–180 |
| **单日基础小计** | **530–1,220** |
| 住宿 / 人 / 晚 | 250–650 |
| 约两小时入门小班课 / 人 / 次 | 350–1,000 |

- **一天滑雪 + 一次课，不住宿：880–2,220 元/人。**
- **两天滑雪 + 一晚住宿 + 一次课：1,660–4,090 元/人。** 计算为 2 × 基础小计 + 住宿 + 课程。
- **另加**出发城市往返大交通、机场至山区等长距离接送、独立景区门票、保险及杂费、单房差、额外课程与预备金。西岭等景区目的地尤其要另核上山门票与索道，吉克普林等要另核景区交通。
- 若雪票含板鞋，或酒店含雪票，先用真实套餐替换对应行，再求和。这个保守的单买模型不能直接拿来判断套餐贵不贵。

## 出发前确认
