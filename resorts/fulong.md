# 崇礼富龙：怎么去、怎么学、怎么做预算

[雪场目录](README.md) · [预算怎么算](../docs/06-budget.md) · [返回首页](../README.md)

**区域：河北张家口崇礼｜资料整理：2026-10-24**

## 先看它适不适合你

富龙与崇礼城区联系紧密，官方介绍包括滑雪、住宿、餐饮及夜场等项目。夜场开放安排需按具体雪季和日期核实。

**更适合：** 倾向住城区、白天上课并兼顾餐饮出行的人。想滑夜场也应先适应照明与雪况，不用把第一天日夜场排满。

## 到达与住宿

比较崇礼站及城区住宿到雪具大厅的具体路线。城区边缘不代表所有酒店都能穿雪鞋步行到达，尤其要核对入口和班车站。

城区酒店和雪场配套住宿都可比较。询价时让商家说明单房价还是人均价，并计算打车、早餐和器材搬运成本。

## 新手安排

先完成教学区练习，安排清楚集合与归还时间。地形公园和夜场是不同功能，不能把公园开放当作新手可以随意穿行。

## 大概要花多少

这张表按成人、非节假日、双人拼房来估，促销和住滑价没算。它的用途是帮你出发前留预算，订票时换成自己的实际价格。

| 输入项目 | 规划预留（元/人） |
| --- | ---: |
| 雪票 / 滑雪日 | 220–550 |
| 基础租赁与必要小件 / 滑雪日 | 100–220 |
| 餐饮 / 滑雪日 | 80–180 |
| 当地短途交通 / 滑雪日 | 40–120 |
| **单日基础小计** | **440–1,070** |
| 住宿 / 人 / 晚 | 150–450 |
| 约两小时入门小班课 / 人 / 次 | 350–900 |

- **一天滑雪 + 一次课，不住宿：790–1,970 元/人。**
- **两天滑雪 + 一晚住宿 + 一次课：1,380–3,490 元/人。** 计算为 2 × 基础小计 + 住宿 + 课程。
- 大交通、保险、单房差、额外课程和预备金另算。偏远山区的机场接送、景区门票和索道也要单独查。
- 票里含板鞋、酒店含雪票时，删掉重复项目再加总。比较住滑套餐也按这个办法。

## 出发前确认

- [ ] 日场与夜场是否分别计时、夜场开放哪些区。
- [ ] 初学区域、魔毯和课后练习区域是否一致。
- [ ] 从酒店到正确雪具大厅的交通方式。
- [ ] 用出行日期的官方报价替换上表；核对退改、时长、租赁、储物和押金。
- [ ] 保存当日雪道图与救援电话；核实所选教学区域的开放状态。
