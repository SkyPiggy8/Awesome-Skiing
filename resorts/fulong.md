# 崇礼富龙：怎么去、怎么学、怎么做预算

[雪场目录](README.md) · [预算口径](../docs/06-budget.md) · [返回首页](../README.md)

**区域：河北张家口崇礼｜资料整理：2026-10-24**

## 先认识这个目的地

富龙与崇礼城区联系紧密，官方介绍包括滑雪、住宿、餐饮及夜场等项目。夜场开放安排需按具体雪季和日期核实。 来源见页末。以下适用人群、行程和预算是编辑建议，不是亲测评价或官方承诺。

**适合怎样的计划：** 倾向住城区、白天上课并兼顾餐饮出行的人。想滑夜场也应先适应照明与雪况，不用把第一天日夜场排满。

## 到达与住宿

比较崇礼站及城区住宿到雪具大厅的具体路线。城区边缘不代表所有酒店都能穿雪鞋步行到达，尤其要核对入口和班车站。

城区酒店和雪场配套住宿都可比较。询价时让商家说明单房价还是人均价，并计算打车、早餐和器材搬运成本。

## 新手安排

先完成教学区练习，安排清楚集合与归还时间。地形公园和夜场是不同功能，不能把公园开放当作新手可以随意穿行。

## 人均预算演算

**以下是用于规划的假设区间，不是本雪场报价，也未完成当季询价。** 成人、非节假日的常规出行场景；不采用促销价和住滑打包价。住宿按双人房两人分摊。若实际报价超出区间，以实际报价重新计算。

| 输入项目 | 规划预留（元/人） |
| --- | ---: |
| 雪票 / 滑雪日 | 220–550 |
| 基础租赁与必要小件 / 滑雪日 | 100–220 |
| 餐饮 / 滑雪日 | 80–180 |
| 当地短途交通 / 滑雪日 | 40–120 |
| **单日基础小计** | **440–1,070** |
| 住宿 / 人 / 晚 | 150–450 |
| 约两小时入门小班课 / 人 / 次 | 350–900 |

- **一天滑雪 + 一次课，不住宿：790–1,970 元/人。**
- **两天滑雪 + 一晚住宿 + 一次课：1,380–3,490 元/人。** 计算为 2 × 基础小计 + 住宿 + 课程。
- **另加**出发城市往返大交通、机场至山区等长距离接送、独立景区门票、保险及杂费、单房差、额外课程与预备金。西岭等景区目的地尤其要另核上山门票与索道，吉克普林等要另核景区交通。
- 若雪票含板鞋，或酒店含雪票，先用真实套餐替换对应行，再求和。这个保守的单买模型不能直接拿来判断套餐贵不贵。
