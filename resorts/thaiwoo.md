# 崇礼太舞：怎么去、怎么学、怎么做预算

[雪场目录](README.md) · [预算怎么算](../docs/06-budget.md) · [返回首页](../README.md)

**区域：河北张家口崇礼｜资料整理：2026-10-24**

## 先看它适不适合你

太舞是结合滑雪、住宿与小镇餐饮的山地度假目的地，官网提供酒店、运动学院和服务咨询信息。

**更适合：** 希望把课程、住宿和非滑雪活动放在同一区域的朋友或家庭。实际适合程度取决于当日教学区域、课程与房价，不能只看小镇照片。

## 到达与住宿

可优先比较太子城站到小镇的接驳，再核对酒店到集合点的步行距离。高铁抵达与上课不要卡得过紧，换装和找集合点都需时间。

小镇内不同酒店、旅舍与公寓的房型权益不同。问清租赁大厅、早餐、寄存及滑雪课集合点，别把酒店名称相近当成同一个位置。

## 新手安排

先选入门课程和合适场次，再订对应住宿。非滑雪同伴可安排独立活动；滑雪者不为赶上山顶餐厅而进入不适合的雪道。

## 大概要花多少

这张表按成人、非节假日、双人拼房来估，促销和住滑价没算。它的用途是帮你出发前留预算，订票时换成自己的实际价格。

| 输入项目 | 规划预留（元/人） |
| --- | ---: |
| 雪票 / 滑雪日 | 250–600 |
| 基础租赁与必要小件 / 滑雪日 | 100–220 |
| 餐饮 / 滑雪日 | 100–220 |
| 当地短途交通 / 滑雪日 | 50–150 |
| **单日基础小计** | **500–1,190** |
| 住宿 / 人 / 晚 | 200–600 |
| 约两小时入门小班课 / 人 / 次 | 400–1,000 |

- **一天滑雪 + 一次课，不住宿：900–2,190 元/人。**
- **两天滑雪 + 一晚住宿 + 一次课：1,600–3,980 元/人。** 计算为 2 × 基础小计 + 住宿 + 课程。
- 大交通、保险、单房差、额外课程和预备金另算。偏远山区的机场接送、景区门票和索道也要单独查。
- 票里含板鞋、酒店含雪票时，删掉重复项目再加总。比较住滑套餐也按这个办法。

## 出发前确认

- [ ] 运动学院是否有所需项目与级别的班。
- [ ] 套餐对应哪个酒店、几人和几天滑雪。
- [ ] 接驳、租赁、初级区的实际开放安排。
- [ ] 用出行日期的官方报价替换上表；核对退改、时长、租赁、储物和押金。
- [ ] 保存当日雪道图与救援电话；核实所选教学区域的开放状态。
