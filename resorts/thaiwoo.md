# 崇礼太舞：怎么去、怎么学、怎么做预算

[雪场目录](README.md) · [预算口径](../docs/06-budget.md) · [返回首页](../README.md)

**区域：河北张家口崇礼｜资料整理：2026-10-24**

## 先认识这个目的地

太舞是结合滑雪、住宿与小镇餐饮的山地度假目的地，官网提供酒店、运动学院和服务咨询信息。 来源见页末。以下适用人群、行程和预算是编辑建议，不是亲测评价或官方承诺。

**适合怎样的计划：** 希望把课程、住宿和非滑雪活动放在同一区域的朋友或家庭。实际适合程度取决于当日教学区域、课程与房价，不能只看小镇照片。

## 到达与住宿

可优先比较太子城站到小镇的接驳，再核对酒店到集合点的步行距离。高铁抵达与上课不要卡得过紧，换装和找集合点都需时间。

小镇内不同酒店、旅舍与公寓的房型权益不同。问清租赁大厅、早餐、寄存及滑雪课集合点，别把酒店名称相近当成同一个位置。

## 新手安排

先选入门课程和合适场次，再订对应住宿。非滑雪同伴可安排独立活动；滑雪者不为赶上山顶餐厅而进入不适合的雪道。

## 人均预算演算

**以下是用于规划的假设区间，不是本雪场报价，也未完成当季询价。** 成人、非节假日的常规出行场景；不采用促销价和住滑打包价。住宿按双人房两人分摊。若实际报价超出区间，以实际报价重新计算。

| 输入项目 | 规划预留（元/人） |
| --- | ---: |
| 雪票 / 滑雪日 | 250–600 |
| 基础租赁与必要小件 / 滑雪日 | 100–220 |
| 餐饮 / 滑雪日 | 100–220 |
| 当地短途交通 / 滑雪日 | 50–150 |
| **单日基础小计** | **500–1,190** |
| 住宿 / 人 / 晚 | 200–600 |
| 约两小时入门小班课 / 人 / 次 | 400–1,000 |

- **一天滑雪 + 一次课，不住宿：900–2,190 元/人。**
- **两天滑雪 + 一晚住宿 + 一次课：1,600–3,980 元/人。** 计算为 2 × 基础小计 + 住宿 + 课程。
- **另加**出发城市往返大交通、机场至山区等长距离接送、独立景区门票、保险及杂费、单房差、额外课程与预备金。西岭等景区目的地尤其要另核上山门票与索道，吉克普林等要另核景区交通。
- 若雪票含板鞋，或酒店含雪票，先用真实套餐替换对应行，再求和。这个保守的单买模型不能直接拿来判断套餐贵不贵。
