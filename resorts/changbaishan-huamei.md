# 长白山华美胜地：怎么去、怎么学、怎么做预算

[雪场目录](README.md) · [预算怎么算](../docs/06-budget.md) · [返回首页](../README.md)

**区域：吉林白山抚松区域｜资料整理：2026-10-24**

## 先看它适不适合你

吉林省政府发布的 2025 年开板信息介绍了面向初中级滑雪者和家庭游客的雪道与度假项目。华美胜地与万达是不同度假区，票券和酒店不混用。

**更适合：** 以基础学习、家庭休闲为主要目标，倾向把滑雪与其他度假项目组合的人。仍需按课程条件和当日雪面判断是否适合。

## 到达与住宿

先核对酒店与雪场准确名称，再安排机场或车站接送。不要只向司机说“去长白山”，应提供订单地址和集合点。

比较酒店的滑雪次数、单双板租赁、娱雪和温泉等具体权益，核对是否需要分别预约。宣传中的项目清单并不意味着都免费。

## 新手安排

以一个初学区和一组明确课程为主。同行儿童与成人可能需要分别上课，非滑雪活动另排，避免因为套餐项目多而压缩休息。

## 大概要花多少

这张表按成人、非节假日、双人拼房来估，促销和住滑价没算。它的用途是帮你出发前留预算，订票时换成自己的实际价格。

| 输入项目 | 规划预留（元/人） |
| --- | ---: |
| 雪票 / 滑雪日 | 200–450 |
| 基础租赁与必要小件 / 滑雪日 | 100–220 |
| 餐饮 / 滑雪日 | 100–200 |
| 当地短途交通 / 滑雪日 | 50–180 |
| **单日基础小计** | **450–1,050** |
| 住宿 / 人 / 晚 | 200–600 |
| 约两小时入门小班课 / 人 / 次 | 350–1,000 |

- **一天滑雪 + 一次课，不住宿：800–2,050 元/人。**
- **两天滑雪 + 一晚住宿 + 一次课：1,450–3,700 元/人。** 计算为 2 × 基础小计 + 住宿 + 课程。
- 大交通、保险、单房差、额外课程和预备金另算。偏远山区的机场接送、景区门票和索道也要单独查。
- 票里含板鞋、酒店含雪票时，删掉重复项目再加总。比较住滑套餐也按这个办法。

## 出发前确认

- [ ] 与其他长白山度假区是否被误订。
- [ ] 课程、初级区、租赁是否对应同一套餐。
- [ ] 儿童年龄、服装尺码与接送安排。
- [ ] 用出行日期的官方报价替换上表；核对退改、时长、租赁、储物和押金。
- [ ] 保存当日雪道图与救援电话；核实所选教学区域的开放状态。
