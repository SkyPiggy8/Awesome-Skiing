# 西岭雪山：怎么去、怎么学、怎么做预算

[雪场目录](README.md) · [预算怎么算](../docs/06-budget.md) · [返回首页](../README.md)

**区域：四川成都大邑｜资料整理：2026-10-24**

## 先看它适不适合你

西岭雪山官网将滑雪场介绍为后山滑雪场区域。景区观光、进入景区的索道和真正滑雪的票务内容需要分别核对。

**更适合：** 成都及周边想把山地观光与短途滑雪组合的人。以重复基础训练为目标时，也可同时比较本地室内真雪馆的交通与课程。

## 到达与住宿

按景区当前交通公告安排到入口及上山方式。不要把到山脚的时间当成到雪具大厅的时间；索道和景区接驳可能占用额外时段。

比较山下与景区内住宿的上山次数、门票权益和早晚通行。日游预留足够归还装备与下山时间，避免只按滑雪结束时间订返程。

## 新手安排

先核实雪况及滑雪项目实际营业，再安排课程。景区门票便宜不等于滑雪便宜；日夜项目、租赁和上山设施按不同费用确认。

## 大概要花多少

这张表按成人、非节假日、双人拼房来估，促销和住滑价没算。它的用途是帮你出发前留预算，订票时换成自己的实际价格。

| 输入项目 | 规划预留（元/人） |
| --- | ---: |
| 雪票 / 滑雪日 | 150–400 |
| 基础租赁与必要小件 / 滑雪日 | 100–220 |
| 餐饮 / 滑雪日 | 80–180 |
| 当地短途交通 / 滑雪日 | 100–300 |
| **单日基础小计** | **430–1,100** |
| 住宿 / 人 / 晚 | 180–500 |
| 约两小时入门小班课 / 人 / 次 | 300–900 |

- **一天滑雪 + 一次课，不住宿：730–2,000 元/人。**
- **两天滑雪 + 一晚住宿 + 一次课：1,340–3,600 元/人。** 计算为 2 × 基础小计 + 住宿 + 课程。
- 大交通、保险、单房差、额外课程和预备金另算。偏远山区的机场接送、景区门票和索道也要单独查。
- 票里含板鞋、酒店含雪票时，删掉重复项目再加总。比较住滑套餐也按这个办法。

## 出发前确认

- [ ] 买的是景区观光还是包含滑雪的套餐。
- [ ] 上山索道、交通车与滑雪设施如何收费。
- [ ] 滑雪项目开放、计时规则和下山末班时间。
- [ ] 用出行日期的官方报价替换上表；核对退改、时长、租赁、储物和押金。
- [ ] 保存当日雪道图与救援电话；核实所选教学区域的开放状态。
