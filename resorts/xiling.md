# 西岭雪山：怎么去、怎么学、怎么做预算

[雪场目录](README.md) · [预算口径](../docs/06-budget.md) · [返回首页](../README.md)

**区域：四川成都大邑｜资料整理：2026-10-24**

## 先认识这个目的地

西岭雪山官网将滑雪场介绍为后山滑雪场区域。景区观光、进入景区的索道和真正滑雪的票务内容需要分别核对。 来源见页末。以下适用人群、行程和预算是编辑建议，不是亲测评价或官方承诺。

**适合怎样的计划：** 成都及周边想把山地观光与短途滑雪组合的人。以重复基础训练为目标时，也可同时比较本地室内真雪馆的交通与课程。

## 到达与住宿

按景区当前交通公告安排到入口及上山方式。不要把到山脚的时间当成到雪具大厅的时间；索道和景区接驳可能占用额外时段。

比较山下与景区内住宿的上山次数、门票权益和早晚通行。日游预留足够归还装备与下山时间，避免只按滑雪结束时间订返程。

## 新手安排

先核实雪况及滑雪项目实际营业，再安排课程。景区门票便宜不等于滑雪便宜；日夜项目、租赁和上山设施按不同费用确认。

## 人均预算演算

**以下是用于规划的假设区间，不是本雪场报价，也未完成当季询价。** 成人、非节假日的常规出行场景；不采用促销价和住滑打包价。住宿按双人房两人分摊。若实际报价超出区间，以实际报价重新计算。

| 输入项目 | 规划预留（元/人） |
| --- | ---: |
| 雪票 / 滑雪日 | 150–400 |
| 基础租赁与必要小件 / 滑雪日 | 100–220 |
| 餐饮 / 滑雪日 | 80–180 |
| 当地短途交通 / 滑雪日 | 100–300 |
| **单日基础小计** | **430–1,100** |
| 住宿 / 人 / 晚 | 180–500 |
| 约两小时入门小班课 / 人 / 次 | 300–900 |

- **一天滑雪 + 一次课，不住宿：730–2,000 元/人。**
- **两天滑雪 + 一晚住宿 + 一次课：1,340–3,600 元/人。** 计算为 2 × 基础小计 + 住宿 + 课程。
- **另加**出发城市往返大交通、机场至山区等长距离接送、独立景区门票、保险及杂费、单房差、额外课程与预备金。西岭等景区目的地尤其要另核上山门票与索道，吉克普林等要另核景区交通。
- 若雪票含板鞋，或酒店含雪票，先用真实套餐替换对应行，再求和。这个保守的单买模型不能直接拿来判断套餐贵不贵。

## 出发前确认

- [ ] 买的是景区观光还是包含滑雪的套餐。
- [ ] 上山索道、交通车与滑雪设施如何收费。
- [ ] 滑雪项目开放、计时规则和下山末班时间。
- [ ] 用出行日期的官方报价替换上表；核对退改、时长、租赁、储物和押金。
- [ ] 保存当日雪道图与救援电话；核实所选教学区域的开放状态。
