# 密苑云顶：怎么去、怎么学、怎么做预算

[雪场目录](README.md) · [预算怎么算](../docs/06-budget.md) · [返回首页](../README.md)

**区域：河北张家口崇礼｜资料整理：2026-10-24**

## 先看它适不适合你

云顶滑雪公园位于崇礼，包含冬奥场地与大众滑雪区域，官网列有分级雪道、魔毯、酒店及使用须知。

**更适合：** 想在度假区连续学习，或同行者已有不同水平的人。冬奥场地身份不代表比赛区域适合入门；选票时以能使用的教学区为准。

## 到达与住宿

可比较太子城站及当地接驳，按所住酒店和租赁大厅核对下车点。历史宣传中的行程时间不能作为当前车次保证。

度假区不同楼栋、酒店和公寓的位置不完全相同。订前确认到课堂和适合的索道是否需要走路或接驳，不把“有缆车”理解成初学者可直接滑行。

## 新手安排

第一天认识雪场图与教学区，学会哪些路线能返回集合点。跨雪场通滑权益先问清实际连接方式，不为了用足票而跨越能力范围。

## 大概要花多少

这张表按成人、非节假日、双人拼房来估，促销和住滑价没算。它的用途是帮你出发前留预算，订票时换成自己的实际价格。

| 输入项目 | 规划预留（元/人） |
| --- | ---: |
| 雪票 / 滑雪日 | 260–600 |
| 基础租赁与必要小件 / 滑雪日 | 100–220 |
| 餐饮 / 滑雪日 | 90–200 |
| 当地短途交通 / 滑雪日 | 50–150 |
| **单日基础小计** | **500–1,170** |
| 住宿 / 人 / 晚 | 200–550 |
| 约两小时入门小班课 / 人 / 次 | 400–1,000 |

- **一天滑雪 + 一次课，不住宿：900–2,170 元/人。**
- **两天滑雪 + 一晚住宿 + 一次课：1,600–3,890 元/人。** 计算为 2 × 基础小计 + 住宿 + 课程。
- 大交通、保险、单房差、额外课程和预备金另算。偏远山区的机场接送、景区门票和索道也要单独查。
- 票里含板鞋、酒店含雪票时，删掉重复项目再加总。比较住滑套餐也按这个办法。

## 出发前确认

- [ ] 大众教学区与赛事、训练封闭区的边界。
- [ ] 票种是否含租赁、夜场或其他雪场权益。
- [ ] 酒店到集合点及下山返回方式。
- [ ] 用出行日期的官方报价替换上表；核对退改、时长、租赁、储物和押金。
- [ ] 保存当日雪道图与救援电话；核实所选教学区域的开放状态。
