# 北大湖：怎么去、怎么学、怎么做预算

[雪场目录](README.md) · [预算怎么算](../docs/06-budget.md) · [返回首页](../README.md)

**区域：吉林省吉林市永吉县｜资料整理：2026-10-24**

## 先看它适不适合你

北大湖官网介绍了分级雪道、魔毯及缆车等设施，是吉林区域的大型滑雪度假目的地之一。设施规模不能代替对初学区的具体了解。

**更适合：** 计划连续练习、希望有不同能力课程选择的雪友。多人同行可共用住宿和餐饮安排，滑行按各自能力分组。

## 到达与住宿

比较经吉林市或长春龙嘉机场到住宿的方案。机场接送是否直达酒店、是否与其他人拼车、返程是否预约，都需要问清。

比较度假区内住宿和周边住宿的接送安排。离雪场近不等于离所需教学区近；提前确认雪具寄存和烘干条件。

## 新手安排

先完成租赁适配与地形说明，再在指定初学区练习。留出室内休息和保暖时间；天气、风或能见度变化时及时调整。

## 大概要花多少

这张表按成人、非节假日、双人拼房来估，促销和住滑价没算。它的用途是帮你出发前留预算，订票时换成自己的实际价格。

| 输入项目 | 规划预留（元/人） |
| --- | ---: |
| 雪票 / 滑雪日 | 280–600 |
| 基础租赁与必要小件 / 滑雪日 | 100–230 |
| 餐饮 / 滑雪日 | 100–220 |
| 当地短途交通 / 滑雪日 | 60–180 |
| **单日基础小计** | **540–1,230** |
| 住宿 / 人 / 晚 | 180–550 |
| 约两小时入门小班课 / 人 / 次 | 350–1,000 |

- **一天滑雪 + 一次课，不住宿：890–2,230 元/人。**
- **两天滑雪 + 一晚住宿 + 一次课：1,610–4,010 元/人。** 计算为 2 × 基础小计 + 住宿 + 课程。
- 大交通、保险、单房差、额外课程和预备金另算。偏远山区的机场接送、景区门票和索道也要单独查。
- 票里含板鞋、酒店含雪票时，删掉重复项目再加总。比较住滑套餐也按这个办法。

## 出发前确认

- [ ] 初学区对应的票与课程能否独立购买。
- [ ] 住滑是否包括头盔、服装、夜场等附加项目。
- [ ] 机场接驳、雪场接驳是否为不同服务。
- [ ] 用出行日期的官方报价替换上表；核对退改、时长、租赁、储物和押金。
- [ ] 保存当日雪道图与救援电话；核实所选教学区域的开放状态。
