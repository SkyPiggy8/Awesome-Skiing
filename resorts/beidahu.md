# 北大湖：怎么去、怎么学、怎么做预算

[雪场目录](README.md) · [预算口径](../docs/06-budget.md) · [返回首页](../README.md)

**区域：吉林省吉林市永吉县｜资料整理：2026-10-24**

## 先认识这个目的地

北大湖官网介绍了分级雪道、魔毯及缆车等设施，是吉林区域的大型滑雪度假目的地之一。设施规模不能代替对初学区的具体了解。 来源见页末。以下适用人群、行程和预算是编辑建议，不是亲测评价或官方承诺。

**适合怎样的计划：** 计划连续练习、希望有不同能力课程选择的雪友。多人同行可共用住宿和餐饮安排，滑行按各自能力分组。

## 到达与住宿

比较经吉林市或长春龙嘉机场到住宿的方案。机场接送是否直达酒店、是否与其他人拼车、返程是否预约，都需要问清。

比较度假区内住宿和周边住宿的接送安排。离雪场近不等于离所需教学区近；提前确认雪具寄存和烘干条件。

## 新手安排

先完成租赁适配与地形说明，再在指定初学区练习。留出室内休息和保暖时间；天气、风或能见度变化时及时调整。

## 人均预算演算

**以下是用于规划的假设区间，不是本雪场报价，也未完成当季询价。** 成人、非节假日的常规出行场景；不采用促销价和住滑打包价。住宿按双人房两人分摊。若实际报价超出区间，以实际报价重新计算。

| 输入项目 | 规划预留（元/人） |
| --- | ---: |
| 雪票 / 滑雪日 | 280–600 |
| 基础租赁与必要小件 / 滑雪日 | 100–230 |
| 餐饮 / 滑雪日 | 100–220 |
| 当地短途交通 / 滑雪日 | 60–180 |
| **单日基础小计** | **540–1,230** |
| 住宿 / 人 / 晚 | 180–550 |
| 约两小时入门小班课 / 人 / 次 | 350–1,000 |

- **一天滑雪 + 一次课，不住宿：890–2,230 元/人。**
- **两天滑雪 + 一晚住宿 + 一次课：1,610–4,010 元/人。** 计算为 2 × 基础小计 + 住宿 + 课程。
- **另加**出发城市往返大交通、机场至山区等长距离接送、独立景区门票、保险及杂费、单房差、额外课程与预备金。西岭等景区目的地尤其要另核上山门票与索道，吉克普林等要另核景区交通。
- 若雪票含板鞋，或酒店含雪票，先用真实套餐替换对应行，再求和。这个保守的单买模型不能直接拿来判断套餐贵不贵。

## 出发前确认

- [ ] 初学区对应的票与课程能否独立购买。
- [ ] 住滑是否包括头盔、服装、夜场等附加项目。
- [ ] 机场接驳、雪场接驳是否为不同服务。
- [ ] 用出行日期的官方报价替换上表；核对退改、时长、租赁、储物和押金。
- [ ] 保存当日雪道图与救援电话；核实所选教学区域的开放状态。
