# 不看长教程、不请私教，也想轻松体验一天

[知识地图](00-knowledge-map.md) · [安全基础](02-basics-and-safety.md) · 更新：2026-10-26

**可以把目标设为接触雪、试穿雪具、在平地感受移动。** 下坡滑行需要控制速度和停止；如果这些还不会，就把活动留在平地或按规则使用娱雪设施。单靠一张清单不能保证安全，但可以避免一开始就把自己放进无法控制的场景。

## 先选当天愿意投入多少

| 你愿意做的准备 | 比较合适的安排 |
| --- | --- |
| 不想学习动作，只想玩雪、拍照 | 买对应娱雪票，使用开放设施；注意雪圈等也有身高、年龄和乘坐要求 |
| 愿意听简短现场说明 | 询问是否有公开体验课/入场说明；在指定平地区域体验穿脱与移动 |
| 愿意学会停止再试缓坡 | 先接受合适的基础指导，现场确认会停、地形合适后再逐步尝试 |
| 什么说明都不愿听 | 选择允许的观景和休闲区域，不进入滑行路线 |

**不请付费教练仍可以利用正规公开课。** 广州热雪奇迹在 2026 年 9—12 月公告中列出每场约 30 分钟的平地公开教学，并有节假日限制。去之前确认是否开课、如何参加、适合哪种板；这类课也不代表已经具备独立下坡能力。见 [广州指南及公告](../resorts/guangzhou-indoor.md)。

## 当天只记住七件事

1. **告诉租赁人员“我零基础”**，请他们检查鞋、板、固定器与头盔；鞋疼、麻、松跟就调整。
2. **请工作人员指出允许的平地体验区、出入口和救援位置。** “初级道”这个名字并不保证你能停下。
3. **先在平地穿脱、站稳、挪步。** 如果站起和停止都没有把握，不向坡顶挪动，也不让人推你起滑。
4. **始终给前方和下方的人留空间。** 起步先看上方，停止处要能被上方看见、且不挡通道。
5. **不会上落的设施先问工作人员。** 魔毯也有上下规则；不跟着朋友直接上高处吊椅。
6. **拍照在允许停留的区域完成。** 不站雪道中间、不在坡顶背面蹲着、不在汇入口集合。
7. **冷、累、看不清或控制变差就休息。** 不为“票没滑回本”多滑最后一趟。

这些行为原则对应 [NSAA 雪场责任准则](https://skisafety.us/your-responsibility-code)，在国内还需遵守所在雪场规则。

## 一个轻松的半日安排

| 环节 | 做什么 |
| --- | --- |
| 出发前 | 确认娱雪/滑雪票、租赁包含项、返程；带手套、袜子、干燥替换用品 |
| 到场后 | 给换装试鞋留足时间，询问实际计时起点 |
| 第一轮 | 现场说明、平地适应，或按工作人员指导玩娱雪设施 |
| 休息 | 补水、检查衣物是否湿、确认体力与心情 |
| 第二轮 | 重复自己已经能控制的活动，拍照、和朋友会合；想学滑行就预约下一次入门课 |
| 离场 | 提前还装备，确认押金处理，换干衣物 |

这里没有“必须滑几小时”的目标。实际运动时间应短于整段在场时间，尤其第一次试鞋、换装和休息会占去不少时间。

## 三种情况直接求助

- **已经上到不会下的雪道**：停在可被看见且不挡路的位置，联系巡逻/工作人员安排下山，不跟随别人硬滑。
- **摔倒后明显疼痛或无法自行安全移动**：请同伴通知工作人员，避免其他滑手碰撞；不要靠拖拽赶紧离开。
- **雪板脱手或装备松脱**：先避免继续滑动，让工作人员帮助处理，不追着失控雪板穿越人流。

朋友最有用的帮助是陪同换装、提醒休息、找工作人员和固定机位拍摄。拉手、推背、把人拖下坡会让初学者失去自主控制，不安排进体验计划。
