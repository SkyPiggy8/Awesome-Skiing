# 单板入门：从单脚移动到连续换刃

[返回首页](../README.md) · [基础知识](02-basics-and-safety.md) · [B 站视频](../resources/videos.md)

本页帮助理解课程顺序和记录练习。单板教学体系的练习安排可能不同，现场教练会按地形、身体条件和已有动作调整。不存在适合所有人的“几小时包换刃”。

## 先认识几个方向

- **Regular / Goofy**：左脚在前 / 右脚在前。没有优劣之分，可在教练指导下试出较自然的站姿。
- **脚尖刃 / 脚跟刃**：分别靠近脚尖和脚跟的一侧，中文也常说前刃、后刃。
- **板头 / 板尾**：沿板长方向的两端；不要把板头板尾和前后刃混淆。
- **上山刃 / 下山刃**：相对当前坡面的位置；会随板的方向改变，不是固定等于脚尖刃或脚跟刃。

先能说清这些词，就能减少听教学口令时的误解。

## 阶段 0：装备、单脚滑行与起身

认识固定器，学习在安全平地穿脱、移动、转身和起身。前脚固定、后脚解开时的蹬滑和平衡，是经过平地和使用某些上山设施的基础。

检查站距、角度和固定器尺寸是否由工作人员调好，不照抄陌生人的角度。两脚固定后失去普通走路的方式，需要在教练指导下学习失衡处理。

**可以继续的表现**：能低速单脚移动和停止，知道如何避免板失控滑走。

## 阶段 1：两侧刃的滑移与停止

**推坡**是在板大体横向坡面时，学习用刃控制向下滑移。先建立脚跟侧与脚尖侧都能控制的感觉，不只练自己不害怕的一侧。

注意观察身体是否整体后仰、低头或过度弯腰；让教练帮助你找到脚踝、膝和髋之间的协调。推坡不是把板永远死压在一个角度上，刃角的变化需要逐渐感受。

**可以继续的表现**：两侧都能在指定范围减速和停止，能听从出发与停下的安排。

## 阶段 2：斜滑与落叶飘

**落叶飘**通常在保持同一侧刃控制的情况下，让板沿坡面左右斜向移动。它帮助建立方向和平衡感，但本身不等于已掌握换刃。

保持观察，避免横穿整条雪道。板头朝向变化、滑移方向变化与刃角变化是不同的事情；如果只靠甩肩把板拖过去，需要回到更简单地形检查动作。

**可以继续的表现**：能在两侧刃上分别控制左右移动，能选择停止位置，而不是一直向一侧漂。

## 阶段 3：J 形弯与单个转弯

在教练选择的极缓坡和充分缓冲区，学习从短距离滑行逐渐转向并结束滑行，分别建立两侧刃的控制。有些课程会使用阶梯、花环等练习作为衔接。

认识**卡刃/逆刃**：板的滑移方向与接触雪面的刃不匹配，可能突然被绊住。不要把“换刃”理解成任何时候都立刻踩向另一侧。板的方向、滑移状态和地形必须共同考虑。

**可以继续的表现**：两侧都能完成可控的单个弯，知道弯在哪里结束，能主动停下。

## 阶段 4：连接转弯

连续转弯是让前一个弯平稳结束，过渡到下一侧，而不是交替急刹。用视线提前规划路线，保持可活动的姿态，不依赖猛烈摆臂或把所有动作都扔给后脚。

在宽度、坡度、人流合适的教学环境中重复；速度开始累积或动作变乱时，先回到已掌握的停止方式，降低练习难度。

以上单脚移动、J 形弯和连接转弯的概念参考 [REI 单板入门](https://www.rei.com/learn/expert-advice/how-to-snowboard.html)。阶段划分和检查项为本仓库编排，不能作为技术考级标准。

## 阶段 5：稳定滑行，再选择进阶方向

完成过一次换刃，不等于能应对更陡坡。先确认你能重复连续转弯、根据人流调整路线、两侧停止、经过适合自己的连接道，并处理轻微雪况变化。

刻滑、平花、反脚、公园和粉雪是不同发展方向。学习新内容时重新选择相应地形和课程，不用把“还不会刻滑”理解成入门失败。

## 常见误区

| 误区 | 更有用的观察 |
| --- | --- |
| 推坡很熟，所以可以去高级道 | 能不能在目标坡度上双侧控速、改变方向并停下 |
| 换刃就是把肩膀猛甩过去 | 上身是否过度旋转，脚下是否还有控制 |
| 害怕时一直压后脚更安全 | 是否失去板头控制，动作是否越来越僵硬 |
| 摔得多说明学得快 | 当前任务、雪况和身体状态是否匹配 |
| 视频里用了某角度，我也该照抄 | 当前脚型、站距、设备和动作目标是否相同 |
