# 滑雪术语小词典

[返回首页](../README.md) · [双板路线](04-ski-learning.md) · [单板路线](05-snowboard-learning.md)

术语帮助交流，不是技术考核。不同教练和体系可能使用不同中文翻译，听不懂时请对方示范并说明适用场景。

| 词语 | 简明解释 |
| --- | --- |
| Ski / Alpine skiing | 本手册主要指高山双板滑雪；越野滑雪等是其他分支 |
| Snowboard | 单板滑雪，两脚固定在同一块板上 |
| 雪道 / Piste / Run | 雪场划定的滑行路线；是否开放看现场标识 |
| 压雪 / Grooming | 使用设备整理雪面，不代表所有位置都松软 |
| 滚落线 / Fall line | 坡面最直接向下的方向 |
| 刃 / Edge | 雪板侧边帮助控制与雪面作用的部分，常有钢刃 |
| 立刃 / Edging | 调节板相对雪面的倾斜程度 |
| 搓雪转弯 / Skidded turn | 允许板产生横向滑移的转弯，用于方向和速度控制 |
| 刻滑 / Carving | 更多由刃沿弧线运行的转弯方式，通常轨迹较窄 |
| 横切 / Traverse | 横向或斜向通过坡面，需要观察和留出他人空间 |
| 侧滑 / Sideslip | 板相对横坡时可控地向下滑移 |
| 弯形 / Turn shape | 在雪面上选择的转弯路线，影响速度与空间占用 |
| 犁式 / Wedge | 双板板尖相对接近、板尾分开的基本形态 |
| 平行式 / Parallel | 双板大体平行完成滑行或转弯；板形不等于全部技术 |
| 外侧板 / Outside ski | 转弯弧线外侧的那块双板，不固定是左板或右板 |
| 前刃 / Toe-side edge | 单板靠脚尖的一侧刃，本文统一用“脚尖刃” |
| 后刃 / Heel-side edge | 单板靠脚跟的一侧刃，本文统一用“脚跟刃” |
| Regular | 单板左脚在前 |
| Goofy | 单板右脚在前 |
| Switch / 反脚 | 以平时不常用的脚在前滑行 |
| 推坡 | 常指在单侧刃控制下滑移、减速的入门练习 |
| 落叶飘 / Falling leaf | 常指保持同侧刃控制、左右斜向移动的练习 |
| J 弯 | 以类似 J 的路线结束一个转向练习 |
| 换刃 | 从一侧刃向另一侧刃过渡，需要配合板的运行状态 |
| 卡刃 / Catch an edge | 刃与滑移方向不匹配而突然被绊住的情形 |
| Flex / 软硬度 | 雪板、雪鞋等的弯曲特性，数值不一定跨品牌统一 |
| Camber / 正拱 | 一类板体纵向弧度；具体整板表现还取决于其他设计 |
| Rocker / 反拱或翘起设计 | 一类板体弧度设计，不等于对所有新手都更合适 |
| Sidecut / 侧切 | 板侧面的弧线几何；标称半径不是实际每个弯的固定半径 |
| Waist width / 腰宽 | 板中部较窄处的宽度；单板要结合雪鞋尺寸看 |
| Mondopoint | 雪鞋常见尺码体系，约对应厘米脚长，仍需试穿 |
| Binding / 固定器 | 连接雪鞋与雪板，必须兼容并正确设置 |
| DIN / 脱离设置俗称 | 双板固定器常见相关用语，不能只按体重或别人数据设置 |
| VLT | 镜片可见光透过率，影响不同明暗条件下的适用性 |
| OTG | 可容纳眼镜的雪镜设计，仍需检查具体尺寸和贴合 |
| 魔毯 / Conveyor | 传送带式上山设施，常见于初学区 |
| 吊椅 / Chairlift | 开放式座椅索道，上落前需掌握使用方法 |
| 吊厢 / Gondola | 厢式索道，器材放置和上下方式听从工作人员 |
| 滑进滑出 / Ski-in ski-out | 住宿与雪道连接的一类条件，不一定适合新手直接滑到门口 |
| 地形公园 / Terrain park | 含跳台、道具等专门地形的区域 |
| 蘑菇 / Moguls | 连续雪包地形，需要相应路线和动作能力 |
| 粉雪 / Powder | 较松散的新雪描述，实际深度和密实程度差异很大 |
| 道外 / Off-piste | 常指压雪道外，管理与开放范围需现场确认 |
| Backcountry | 通常指度假区常规管理外的山区活动，不属于本文入门内容 |

理解动作时返回 [基础知识](02-basics-and-safety.md)；遇到设备适配问题返回 [装备指南](03-equipment.md)。
