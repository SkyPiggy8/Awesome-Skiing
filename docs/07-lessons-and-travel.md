## 要不要请教练，能自学吗？

**零基础优先安排一次合适的现场入门指导；已有控制能力后，可以用视频、短文和录像辅助自主练习。** 自学需要自己判断地形、控制速度、发现错误并选择退阶练习，这些恰好是初学者最缺的部分。教练的价值包括现场反馈，不只是带你坐一次缆车。

| 情况 | 比较实际的选择 |
| --- | --- |
| 完全不会移动、刹停和上落设施 | 零基础课程，先把预算留给入门阶段 |
| 预算紧，但想学滑行 | 同项目同水平小班、课程含票租套餐、正规的公开体验课；逐项比总价 |
| 会在合适地形稳定停下、转弯，想巩固 | 按明确目标自主练习，定期录像和反馈 |
| 同一个错误反复出现、害怕、两侧表现差很多 | 一次有针对性的诊断课，课后执行少量练习 |
| 只想玩雪，没兴趣学习动作 | [轻松体验安排](11-first-day-without-lessons.md)，不用为了拍照硬上雪道 |

不是每次都必须上一整天私教，也不能用“别人自学成功”推断自己当前适合独自下坡。预算紧时，把昂贵全套装备延后，常能腾出第一次课的钱。参考 [PSIA-AASI 入门资源](https://thesnowpros.org/learn-to-ski-or-snowboard/) 与 [REI 首次出行建议](https://www.rei.com/learn/expert-advice/planning-your-first-time-skiing-or-snowboarding.html)。

**双板一分钟预习**：身体保持能活动的站姿，眼睛看前方；犁式指板头较近、板尾分开，通过合适的弯形与刃控调节速度。雪杖不是刹车器，也不能靠坐到后面获得稳定停止。具体幅度和练习坡度需要现场判断。

**单板一分钟预习**：先认识前脚、后脚及脚跟侧/脚尖侧刃；单脚蹬行是平地移动和上下部分设施的基础。推坡练习横向持板时的刃控，落叶飘练习同一条刃上的方向变化，连续换刃还包含转换刃与弯形控制；“会落叶飘”不等于“可以去陡坡”。

短文用于看懂下一步，不是一次读完就能照口令独立练习的保证。完整阶段、练习条件与退阶提示见双板/单板路线；视频的作者与审看状态见 [视频目录](../resources/videos.md)。

## 怎么选第一位教练

先确认教单双板中的哪一种、是否熟悉成人零基础或儿童教学、能否在所选雪场合法开展课程。证书名称、发证机构、有效状态与实际教学经历可以询问，但证书等级本身不保证与你沟通合适。

好的初次沟通应该能讲清：在哪里集合、课程包含哪些内容、什么条件下调整计划、如何反馈问题、课后应该在哪练习。不要把“包会”“保证几小时上中级道”作为购买理由。

| 课程类型 | 适合的情形 | 需要确认 |
| --- | --- | --- |
| 小班 | 预算有限、能接受共同进度 | 上限人数、是否同水平、语言、分组方式 |
| 一对一 | 需要更多即时反馈或个别安排 | 实际课时、场地和装备是否另外付费 |
| 亲友拼班 | 项目与能力接近 | 每个人都适合该组，不能只看人数便宜 |
| 儿童课 | 儿童参与 | 年龄条件、监护交接、休息与保暖安排 |

## 约课前可直接复制的问题

- 我第一次滑单板/双板，这个班是否完全零基础？
- 这笔费用按人还是按组？一组最多几人？
- 课时从哪个环节开始，排队和换装是否计入？
- 雪票、租赁、头盔、服装、柜子是否包含？
- 教学区域和集合地点在哪里？天气或设备停运如何处理？
- 课程结束后，会告诉我适合练习什么、在哪里练吗？

视频能帮助预习术语和复盘，但不能观察你当时的平衡、疲劳和周边人流。PSIA-AASI 的 [入门页面](https://thesnowpros.org/learn-to-ski-or-snowboard/) 也强调了现场反馈的作用。

## 交通安排

具体出站路线见 [雪场交通速查](../resorts/transport.md)，广州例子直接看 [广州北站到热雪奇迹](../resorts/guangzhou-indoor.md)。

**高铁**：先选对到站，再比较接驳。名字里都有“崇礼”不意味着同一个站；“距离近”也不等于拖着雪具能走过去。查清接驳发车点、预约和末班时间。

**飞机**：把机场到雪场的道路时间单独算进去。机票目的地写“阿勒泰地区”不代表抵达了每座雪场附近。长距离或山路接驳不要只看地图晴天估算。

**自驾**：提前查天气和道路管理信息，了解车辆及驾驶能力是否适合冰雪路况；不把冬季山路当普通城市驾驶。避免赶夜路和疲劳驾驶，必要时选合规接驳。

**携带自有雪具**：按实际承运公司的运动器材规则核实尺寸、重量和费用；不要照抄别家航司的规定。尖锐部位妥善保护，随身用品与托运用品按规定分装。

## 怎么选住宿

先读 [住滑权益与算账实例](12-tickets-and-stay.md)，将套餐适用日期、人数和租赁逐项填入订单比较。

比较“到教学集合点的全过程”，而不只是酒店到雪场的直线距离。滑进滑出也可能要求你先能滑某条连接道，新手需要确认步行或车辆方式。

住滑套餐要分别核对入住日、退房日、单双板租赁、人数和儿童权益。住市区可增加餐饮选择，但要计入每天接驳和早起时间；住山区应核对晚餐、烘干、返程车辆与恶劣天气安排。

## 保险与联系方式

投保前核对所选滑雪活动、地区和日期是否在保障范围，查看医疗、救援、第三方责任、除外条款及理赔材料要求。普通旅行险是否覆盖滑雪不能仅从名称判断。本仓库不推荐保险产品，也不解释个案责任。

手机离线保存酒店、接驳与雪场救援联系方式，以及雪道图。双方约定走散后的集合点；山上网络不稳定时，不能只依靠即时聊天定位。

## 朋友一起滑的约定

需要朋友帮拍时，使用 [固定机位、短片与复盘流程](13-filming-and-progress.md)。

按能力分组，在约定的餐厅或休息区会合。技术较好的同伴不要用拉手、推背或“你跟着我就行”代替教学。拍照选允许停留的位置，经过雪道或公园时不为镜头挡路。

第一次远途雪旅尽量以一个雪场为主。换酒店、搬行李和换租赁会占用体力和练习时间；想增加景点时，把它安排成独立时段，不在疲劳后继续赶行程。
