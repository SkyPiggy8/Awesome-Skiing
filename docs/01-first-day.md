# 第一次滑雪：从订票到归还装备

[返回首页](../README.md) · 下一篇：[基础知识](02-basics-and-safety.md)

还没决定学什么？先看 [六问知识地图](00-knowledge-map.md) 和 [单双板选择](10-ski-or-snowboard.md)。下面按“约了入门课”的一天来排；只想看看雪、拍拍照，可以走 [轻松体验路线](11-first-day-without-lessons.md)。

第一天的成功标准很简单：知道装备怎么用，能在合适的教学地形上控制速度，知道什么时候应该停下来。不要把“坐上最高的缆车”当成入门任务。

## 1. 先选单板还是双板

| 维度 | 双板 | 单板 |
| --- | --- | --- |
| 装备与站姿 | 两脚分别固定在两块板上，大体面向行进方向 | 两脚固定在同一块板上，身体侧向站立 |
| 最初的适应 | 两脚可分开移动；需要处理两块板的方向与距离 | 需要适应侧身、单脚移动和前后刃平衡 |
| 平地与连接道 | 可用步行、蹬滑等方法移动 | 有时需要解开后脚滑行；平缓连接道可能较费力 |
| 后续路线 | 休闲滑行、平行转弯、刻滑、地形等 | 连续转弯、刻滑、平花、地形等 |
| 如何决定 | 喜欢这种滑行方式，能找到适合的课程 | 喜欢这种滑行方式，能找到适合的课程 |

一次体验尽量选一种。中途换板当然可以，但要重新领鞋、调装备、适应站姿，短场次里往往不划算。

## 2. 订之前确认六件事

1. **去滑雪还是去玩雪**：娱雪票、观光票、初级区票和全山票是不同商品。第一次别多花钱买自己用不到的区域。
2. **教学区域是否开放**：雪场开门不等于初学区已经开放，雪季刚开始时尤其要问清。比如 11 月 1 日的万龙曾经只开一条道，遇到类似情况就换日期。
3. **租赁包含什么**：板、鞋、固定器和头盔通常能租，但每个套餐不同。介意卫生就带一瓶可用于相应材质的清洁喷雾；贴身用品自己准备。
4. **课程怎么计费**：按人还是按组、人数上限、单双板、课时长度、是否包含票和租赁。
5. **计时与退改**：入园、领卡、领雪具还是过闸开始计时？室内场常给换装余量，夜场也有固定起止时间，直接以当天商品页为准。
6. **最后一段怎么到**：高铁和机票买好后，再查车站到雪具大厅的接驳。冰雪路面不熟就别勉强自驾，预约接送更省心。

## 3. 在家准备

- 贴身排汗层、按天气选的中间保暖层、防风防水外层。
- 一双合脚的中长筒滑雪袜、防水保暖手套、护脸或脖套。
- 证件、手机、充电设备、饮水、少量零食、防晒用品、干燥替换衣物。
- 头盔、雪镜、合适护具可以自备，也可以提前确认租赁。
- 带好预约信息，确认当地日期和场次，不凭旧截图直接到场。

不要把两双厚袜子和裤脚一同塞进雪鞋。首日不必购买雪板、固定器和全套高级装备，见 [租买顺序](03-equipment.md)。

## 4. 到场后的顺序

**换票 → 存物 → 领取和试穿装备 → 找教练 → 热身 → 平地适应 → 教学区练习。**

给换装和租赁留出充足时间，特别是周末。领装备时主动告诉工作人员：第一次滑、单双板、身高、体重、年龄、鞋的实际穿着感受。双板固定器由工作人员调整；别替别人填写身体数据。

试穿雪鞋后站立、屈膝，检查脚趾是否被挤弯、脚跟是否明显抬起，有麻木或局部疼痛立即换码或调整。头盔扣好后不应轻易前后晃动，雪镜与头盔一起试。

拍下租赁装备原有划痕和租赁规则。记住柜号和归还地点；手机存好雪场救援电话。

## 5. 第一节课应该得到什么

合适的入门课应包含装备使用、如何移动和停下、选择地形、基本避让及上落设施。教练应了解你的目标、顾虑和实际表现。

| 阶段 | 练习目标 | 暂时不要追求 |
| --- | --- | --- |
| 平地 | 穿脱装备、转身、小范围移动、站立平衡 | 速度和大幅度动作 |
| 极缓教学坡 | 低速滑行、减速、停止 | 靠摔倒完成每次停车 |
| 合适教学区 | 在指导下改变方向，重复稳定动作 | 为了和朋友同行而换更难雪道 |
| 课后复盘 | 说得清今天会什么、还不会什么 | 用一次成功判断全部掌握 |

不规定“第一天必须换刃”或“第三天必须平行”。疲劳、雪况、人数、个人经历都会影响进度。

## 6. 一天怎么安排

上午先完成换装、课程与短时间练习；中间安排饮水和休息。午后根据精神、体力、能见度和雪面变化决定继续什么。出现动作明显变形、反应变慢、疼痛或持续寒冷时结束当天练习。

朋友可以一起吃饭和休息，滑行时按能力分组。不要让熟练朋友把你带上不熟悉的缆车，再告诉你“慢慢滑就行”。如果在上站发现不能安全下滑，找工作人员安排下山方式。但凡你有朋友知道你第一次滑雪还带你上高级道说没事儿直接翻脸绝交，单板还好双板直接化身鱼类

## 7. 结束前别漏掉

- 提前归还全部租赁用品，确认押金或预授权处理。
- 换干衣物，烘干湿手套；不要把湿装备长时间闷在袋里。
