## 三条可以直接照着走的路线

**A｜只想周末玩一玩**：选近场 → 分清娱雪与滑雪票 → 核对租赁 → 带好贴身用品 → 听现场说明 → 平地体验或按规则玩娱雪设施 → 体力还够时结束。今天开心、没冻着、没被迫上难道，就是一次好体验。

**B｜想认真学会滑行**：选项目 → 找零基础小班/私教 → 看对应视频的入门部分 → 上课解决停止与移动 → 在同等级地形复习 → 记录一个问题 → 决定下一次课和下一次练习。先完成一次，再决定是否购鞋、购板或办卡。

**C｜已有基础，想出活儿**：说清目标动作和前置能力 → 在熟悉雪道拍一段完整滑行 → 找出一个可观察的问题 → 得到教练或可靠教学的反馈 → 练习 → 用相同机位再拍。拍得好看和控制得稳定要分别检查。

## 出门前的十分钟

- **票**：日期、单双板、滑雪/娱雪、区域、时长、计时起点、退改。
- **装备**：租赁含哪些，手套袜子自备没有，雪鞋和头盔能否换码。
- **交通**：最后一段接驳、末班、回程预留；广州例子见 [广州北站到雪场](../resorts/guangzhou-indoor.md)。
- **安全**：知道教学区、停止位置、雪场救援联系方式；不会控制时不用缆车升级地形。
- **保暖**：按温度、风和运动量选层次，面罩湿了能换；见 [装备页](03-equipment.md)。

## 怎么使用 AI、论坛和小红书

这份地图是 **AI 辅助整理与编辑归纳**，没有组织“几百位雪友调查”。AI 可以帮你列问题、算费用、比较路线；决定性信息要落回原作者、雪场和交通运营方。论坛用来发现不同体验，小红书用来看路线图、现场环境和装备上身细节，不能靠点赞数证明所有动作都正确。

每条社区推荐应说明“为什么值得看、看过哪些内容、哪里还未核实”。[社区图文与核验记录](../resources/community-notes.md) 单独维护，读不到正文的链接不能冒充精选。价格、班车、公开课等动态内容都要按出行日再确认。
