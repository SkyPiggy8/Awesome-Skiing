# 滑雪预算：把票、住、课、租和交通一起算

需要具体比价步骤和住滑例子，先看 [雪票怎么买、住滑怎么算](12-tickets-and-stay.md)；如何兼顾钱、进步和雪时，见 [投入取舍](13-filming-and-progress.md)。本页保留完整旅行预算模型。

编制日期：**2026-10-24**。本页和各雪场的数值是**编辑制定的规划假设**，用于比较不同花费结构，未经逐日询价，不是官方报价、统计均价或“最低多少钱能玩”。实际出行必须替换成同日期、同权益的报价。

## 一、总费用公式

**总费用 = 往返大交通 + 当地接驳 + 住宿 + 雪票 + 租赁 + 课程 + 餐饮 + 保险及杂费 + 预备金。**

- 先统一单位：元/人、元/房/晚、元/组/小时不能直接相加。
- 酒店双人房按实际分摊人数计算；一个人住不能沿用双人分摊价。
- 教练按组计费时，先确认允许的实际人数和等级，再分摊；不同水平不宜为了省钱硬拼。
- 住滑套餐已含雪票或租赁时，从单买项目中移除这些费用，不能重复加。
- 预授权、可退押金不是最终支出，但要预留支付额度。

## 二、雪场页预算的统一口径

每个条目给出四个**按人、按滑雪日**的预算输入：雪票、基础租赁与必要小件、餐饮、当地交通。另列住宿的**每人每晚**预算，以及**一次约两小时入门小班课的人均预算**。

**单日基础小计 = 雪票 + 租赁 + 餐饮 + 当地交通。**

**两天一晚 + 一次课 = 2 × 单日基础小计 + 1 晚住宿 + 一次课。**

每次课程的实际人数、时长和包含项目需重新确认。该总计**不含**从你的出发城市往返目的地的大交通、保险、购物、额外课程、单房差、独立景区门票及预备金；当地交通仅是市区/酒店与雪场的短途接驳预算，**不包含机场到偏远山区的包车**。

室内场以一次约 3–4 小时滑雪场次测算，不将其和室外全天票视作同一权益。节假日、雪季初末、早鸟卡和酒店套餐都可能显著改变实际金额。

## 三、三个可以照着算的例子

以下所有数字都是**演算输入**，不是任何一家雪场的报价。

### A. 本地周边一天，第一次体验

| 项目 | 输入（元/人） |
| --- | ---: |
| 雪票 | 220 |
| 基础租赁和小件 | 120 |
| 入门小班课程一次 | 500 |
| 当地往返交通 | 100 |
| 餐饮 | 90 |
| 保险及杂费预留 | 30 |
| 小计 | **1,060** |
| 预备金约 15%，取整 | 160 |
| 规划合计 | **1,220** |

如果 220 元雪票已经包含板、鞋，就把 120 元改为尚未包含的服装、护具、柜子等实际费用，不全额重复计算。

### B. 两天一晚的雪场周末

| 项目 | 计算 | 元/人 |
| --- | --- | ---: |
| 往返大交通 | 单独询价后的假设 | 300 |
| 当地交通 | 80 × 2 天 | 160 |
| 住宿 | 600 元/房/晚 ÷ 2 人 × 1 晚 | 300 |
| 雪票 | 350 × 2 天 | 700 |
| 租赁和小件 | 140 × 2 天 | 280 |
| 入门课 | 一次约两小时小班 | 600 |
| 餐饮 | 120 × 2 天 | 240 |
| 保险及杂费预留 | 整趟行程 | 40 |
| 小计 | | **2,620** |
| 预备金约 15%，取整 | | 400 |
| 规划合计 | | **3,020** |

若周五晚到、周日晚回，实际住两晚，应再加一晚住宿。不要把“两天滑雪”误记成“只住一晚”。

### C. 四天三晚，滑三个白天

| 项目 | 计算 | 元/人 |
| --- | --- | ---: |
| 往返机票等大交通 | 演算假设 | 1,800 |
| 机场及酒店接驳 | 单独预留 | 400 |
| 住宿 | 300 × 3 晚 | 900 |
| 雪票 | 350 × 3 天 | 1,050 |
| 租赁和小件 | 150 × 3 天 | 450 |
| 入门课 | 600 × 2 次 | 1,200 |
| 餐饮 | 120 × 4 天 | 480 |
| 保险及杂费预留 | 整趟行程 | 80 |
| 小计 | | **6,360** |
| 预备金约 15%，取整 | | 960 |
| 规划合计 | | **7,320** |

行程预算按旅行天数算餐饮，按住宿晚数算酒店，按真正上雪天数算雪票，三者不是同一个数字。

## 四、看套餐时逐项核对

| 容易误读的文字 | 应确认的问题 |
| --- | --- |
| 含滑雪 | 观光、娱雪还是滑雪？初级区还是全山？ |
| 双人住滑 | 两人都含吗？入住日和退房日能否滑？ |
| 含雪具 | 板、鞋、固定器、杖之外，头盔、雪镜是否含？ |
| 三小时课程 | 换装、排队是否计时？实际教学多久？ |
| 全天畅滑 | 起止时间？能否中途出场？夜场是否另买？ |
| 免费接驳 | 哪个站点、什么日期、是否预约、末班几点？ |
| 儿童免费 | 身高/年龄条件？是否仅免雪票而不免租赁课程？ |
| 早鸟/季卡 | 黑名单日期、预约限制、可否退款、可否转让？ |

## 五、如何省钱更有效

先比较**到场并完成有效练习的总成本**。近一些、能多次去、合适的教学区域，可能比便宜但遥远的雪票更划算。条件允许时比较工作日；根据实际到场时间选择场次；住宿选位置时把接驳费和时间一起算。

可以节省重复购买衣物、非必要购物和高级装备的支出；不要通过不合脚的雪鞋、来历不明的头盔或缺少课程预算来硬压总价。

季卡粗略回本天数 = 季卡总成本 ÷ 每次真正节省的费用。但如果季卡不含租赁、节假日不可用或你实际只能去几天，这个计算需要调整。不要按理想出勤次数购买。

## 六、历史价格与现价要分开
