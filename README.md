# Awesome-Skiing · 滑雪开源指南

**从第一次想去滑雪，到能自己安排一趟雪旅。**

一份面向中文读者的滑雪手册，覆盖高山双板与单板：基础知识、第一次上雪、装备租买、学习路线、雪场选择、预算与出行。欢迎雪友通过 Issue 和 Pull Request 补充、纠错。

**只推荐装备类型与选择方法，不推荐品牌、型号，不放返佣购买链接。** 不需要先买齐装备，也不需要先弄懂所有术语。

首版整理日期：**2026-10-24**。预算均为人民币、人均规划测算，**不是雪场报价**；2026—2027 雪季具体票价、开放雪道与接驳，以出行日期的官方信息为准。每个雪场页面都有来源与待确认事项。

## 我们如何维护信息

- **事实**：给出官方或可追溯来源；历史资料标明年份。
- **建议**：说明适用人群和前提，不写“所有新手都适合”。
- **预算**：公开计算口径；住滑套餐中的雪票不重复计费。
- **教学**：文字用于预习和复盘；视频注明作者、阶段及核验限制。上雪练习需匹配地形和现场指导。
- **经验**：写明到访日期、单双板、个人水平及当时雪况；不把一次体验写成永久结论。

本手册面向**开放、管理中的雪道和教学区**。道外、雪崩地形、跳台和竞速训练需要另外的专业课程与条件，不在入门路线内。
