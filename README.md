# Awesome-Skiing · 中文滑雪入门指南

**第一次滑雪不知道从哪下手？先把这六个问题搞明白。**

我把散落在 B 站、小红书、雪场官网和论坛里的入门信息整理到了这里。单板和双板都写，重点是第一次怎么准备、按什么顺序学、装备怎么买，以及雪票和住宿怎么少花冤枉钱。

这个项目不带货，只讲装备类型和选择方法。板、鞋和固定器第一次先租，滑过几次再决定买什么，通常比照着博主清单下单靠谱。

- [下载统一 PDF 手册](output/pdf/Awesome-Skiing-Handbook-CN.pdf)：适合坐车、坐飞机时离线看。
- [焚诀资源 · 中英文离线资料库](焚诀资源（飞机高铁上看完直接变专家）/README.md)：收录 JSBA 单板教程、双板技能与力学、学习进阶和教练教学资料，按用途选读。

## 第一次来，按这六个问题看

| 你现在最想知道什么 | 先说结论 | 继续看 |
| --- | --- | --- |
| 单板还是双板？ | 只想体验一天，我更建议先试双板；就是冲着单板来的，直接学单板，第一天把预期放低一点 | [单双板怎么选](docs/10-ski-or-snowboard.md) |
| 第一次要买什么？ | 先买贴身层、袜子、防水手套和护脸。板、鞋、固定器先租 | [装备指南](docs/03-equipment.md) |
| 要不要请教练？ | 零基础至少先看入门视频，最好上一节能教会停止、移动和摔倒处理的课 | [教练与自学](docs/07-lessons-and-travel.md) |
| 不请教练，只想玩一天呢？ | 留在平地、娱雪区或公开体验课。还不会停，就别坐缆车上坡 | [轻松体验路线](docs/11-first-day-without-lessons.md) |
| 第一次去哪滑？ | 南方先找近一点的室内雪场；北方可以比较近郊教学场。第一次没必要为了名气跑太远 | [雪场目录](resorts/README.md) · [交通速查](resorts/transport.md) |
| 怎么省钱？ | 室内票可以比官方、平台和闲鱼；外滑两天以上再比较住滑。先算落地总价，别只看一张低价雪票 | [雪票与住滑](docs/12-tickets-and-stay.md) · [预算](docs/06-budget.md) |

想知道当天从换票到还装备怎么走，直接看 [第一次滑雪](docs/01-first-day.md)。想跟着视频学，去 [教学视频导航](resources/videos.md)：双板以楚格山里人为主，单板入门看黄嘉蓝，稳定换刃后再看 SAM。
