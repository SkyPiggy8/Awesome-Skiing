**目录整理日期：2026-11-08。共 16 个文件：14 份 PDF、2 份 Word，其中两份 JSBA PDF 内容完全相同。** 下方简介依据本地文件的正文、目录和署名整理，页数按 PDF 实际页面计。

## 来源与使用说明

- **JSBA 中文版**：原作为日本单板滑雪协会 2025 年版《单板教程》。封面署名：公子若翻译序章与 Part 3，雪鱼翻译 Part 1、2、4，西西翻译资料编；西西校对，公子若排版。封面注明 **“仅供交流学习，严禁付费使用”**。
- **CSIA 资料**：五大技能框架的文件名标注“非官方中文版”；《技能框架实战》署名译者为“柯南爱滑雪”，完成日期为 2024-08-24。CAT 与课程示范的中文译者信息可继续补充。
- **PSIC / PSIE 资料**：技术蓝图、进阶和力学等英文文件可见 Professional Ski Instructors of Canada 署名；两份中文等级概述可见 Professional Ski Instructors of Europe 与“氧气滑雪 O2 Snowsports”标识。The Adventure 文件同时可见 PSIE.PRO 和加拿大机构版权署名，目录保留文件自身标识。中文《力与平衡》的译者信息可继续补充；Adventure Builder 按草稿收录。
